# Приложение A. Нормативные ссылки

В этом приложении перечислены документы, на которые опирается спецификация MQTT 5.0. Ссылки на них обязательны для корректной реализации.

## A.1. Обязательные нормативные ссылки

- **RFC 2119** — «Key words for use in RFCs to Indicate Requirement Levels» (S. Bradner, March 1997).
  Определяет ключевые слова MUST, MUST NOT, SHOULD, SHOULD NOT, MAY.

- **RFC 8174** — «Ambiguity of Uppercase vs Lowercase in RFC 2119 Key Words» (B. Leiba, May 2017).
  Уточняет, что ключевые слова имеют нормативную силу только при написании ЗАГЛАВНЫМИ буквами.

- **RFC 3629** — «UTF-8, a transformation format of ISO 10646» (F. Yergeau, November 2003).
  Определяет кодировку UTF-8, используемую для строк в MQTT.

- **RFC 6455** — «The WebSocket Protocol» (I. Fette, A. Melnikov, December 2011).
  Определяет транспорт WebSocket, используемый в MQTT over WebSocket.

## A.2. Дополнительные нормативные ссылки

- **ISO/IEC 10646** — Universal Coded Character Set.
  Определяет кодовые точки Unicode.

- **RFC 3986** — «Uniform Resource Identifier (URI): Generic Syntax».
  Используется для идентификации серверов в Server Reference.

## A.3. Ненормативные ссылки

Полезные для понимания, но не обязательные:

- **MQTT Version 3.1.1 (OASIS Standard, 2014)** — предыдущая версия.
- **MQTT for Sensor Networks (MQTT-SN) Version 2.0** — расширение для сенсорных сетей.
- **RFC 5246** — TLS 1.2.
- **RFC 8446** — TLS 1.3.
- **RFC 7519** — JSON Web Token (JWT).
- Различные публикации и реализации, упомянутые в основном тексте.
